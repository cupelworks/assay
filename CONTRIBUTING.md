# Contributing to Assay

Thank you for your interest in Assay.

Assay is open source, but it is **not accepting code contributions**. Pull requests are
closed without review, whatever their size.

## Reporting a bug or suggesting an idea

Issues are welcome. Please [open an issue](../../issues/new) to:

- **report a bug**: what you did, what you expected, what happened instead, and the
  version (`GET /health/worker` returns it);
- **suggest an idea**: the problem you'd like Assay to solve, and why it matters to you.

## Please don't include patches

Don't paste code, diffs or patches into an issue. The maintainer writes every fix
independently, so a described problem is more useful than a proposed change, and it
keeps the project's code under one author.

## Security problems

Don't report a vulnerability in a public issue. Report it privately instead: on this
repository's **Security** tab, choose **Report a vulnerability**. See
[SECURITY.md](SECURITY.md) for what to include.
